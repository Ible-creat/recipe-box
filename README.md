# 🍽️ Recipe Box & Smart Meal Planner

A React app to save favorite recipes, plan weekly meals on a calendar, and auto-generate consolidated shopping lists.

## Features
- Save and manage recipes with ingredients and instructions
- Weekly meal planning calendar (breakfast, lunch, dinner)
- Auto-generated smart shopping list from planned meals
- Ingredient consolidation and unit conversion
- Search, filter, and sort recipes

## Tech Stack
- React 19 + Vite
- React Router
- Tailwind CSS
- Vitest + Testing Library
- LocalStorage for persistence

## Getting Started
```bash
npm install
npm run dev
```
